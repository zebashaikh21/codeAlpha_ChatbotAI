# AI ChatBot

## Description
AI ChatBot is a Java-based chatbot that uses Natural Language Processing (NLP) techniques and rule-based responses to interact with users. It can answer frequently asked questions related to Java, OOP, DSA, and programming concepts through a graphical user interface built with Java Swing.

## Features
- Java-based chatbot
- NLP intent detection
- Rule-based responses
- FAQ knowledge base
- Java Swing GUI
- Real-time interaction

## Technologies Used
- Java
- Swing
- HashMap
- OOP Concepts
